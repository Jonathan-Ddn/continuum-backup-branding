Privacy policy — Backup aionis

Backup aionis is a personal OAuth client used only by its owner to store and retrieve encrypted backup archives on Google Drive.

Google user data

Access is limited to the Google Drive scope drive.file: only files and folders created by this application. It does not access other Drive content.

How data is used

Files are encrypted locally with age before upload. Data is not sold, shared with third parties, or used for advertising. There is a single user.

Storage

OAuth tokens are stored on the owner’s private server. The decryption key is kept offline, separate from Drive.
